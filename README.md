# LES-BEC

This includes the data shown in [Machine learning interatomic potential can infer electrical response](https://arxiv.org/abs/2504.05169).

In particular, this repository contains the training sets, training scripts, BEC inference scripts, md scripts with and without external electric fields, and trained `CACE` potentials
